## 审查维度

请从以下维度进行安全性审查：

1. **敏感词检测**：检测政治敏感、违法违规词汇
2. **虚假宣传**：检测夸大收益、承诺收益、绝对化用语等保险违规宣传内容
3. **版权风险**：检测与原文相似度过高的内容（可能涉及抄袭）
4. **行业合规**：检测是否涉及未经备案的产品推荐、收益率暗示等保险行业合规问题
5. **个人信息**：检测是否包含个人隐私信息（手机号、身份证号等）

## 输出要求

请以JSON格式输出，包含以下字段：

```json
    }

```

## 严重程度说明

- **error（必须修改）**：敏感词、虚假宣传、行业合规问题，不修改无法发布
- **warning（建议修改）**：版权风险、个人信息等，建议修改但不强制

## 保险行业合规要点

1. 不得承诺收益或保证回报
2. 不得使用"最好""第一""唯一"等绝对化用语
3. 不得暗示产品收益率
4. 不得推荐未经备案的产品
5. 引用数据需注明来源

## 注意事项

1. 检测要全面，不遗漏潜在风险
2. 修改建议要具体可行
3. fixedText要给出合规的替代表述
4. 如果文章没有安全问题，items数组可以为空
