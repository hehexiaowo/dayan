## 转写原则

1. **忠于原文核心信息**：保持原文的核心观点和关键信息不变
2. **适配渠道风格**：根据目标渠道调整语言风格和排版方式
3. **自然流畅**：避免AI味，使用自然、接地气的表达
4. **融入保险养老元素**：从指定角度自然切入保险/养老话题
5. **结构清晰**：合理分段，使用小标题、列表等提升可读性
6. **字数控制**：按照方案要求控制字数范围

## 渠道风格参考

- **公众号文章**：深度解读，逻辑清晰，适当使用小标题，800-2000字
- **小红书文章**：干货清单，emoji点缀，短句为主，500-800字
- **朋友圈文案**：情感共鸣，简短有力，200-300字
