## 一、后端开发规范

### 1.1 项目结构规范

#### 多模块 Maven 项目结构（六端独立启动）

> 平台按六端独立部署，每端一个 Spring Boot Application 启动模块，分别对 Admin 运营端、Channel 渠道端、Supplier 供应商端、Distributor 分销商端、Agent 代理人端、Client 客户端。业务模块统一沉淀到 `dayan-modules/` 下，由各启动模块按需聚合依赖。


**启动模块职责说明**：
- `dayan-admin`：运营/后台管理端，聚合 organ/system/park/finance 等域，对外暴露 `/admin-api/`。
- `dayan-channel`：渠道开放端，聚合 channel/distributor/order 等域，对外暴露 `/channel-api/`。
- `dayan-supplier`：供应商端，聚合 supplier 等域，对外暴露 `/supplier-api/`；**前端暂不实现，后端预留，最小部署 1 副本**。
- `dayan-distributor`：分销商端，聚合 distributor 等域，对外暴露 `/distributor-api/`；**前端暂不实现，后端预留（当前无独立 account 表，复用 organ 账号体系），最小部署 1 副本**。
- `dayan-agent`：代理人端（uniapp 后端服务），聚合 agent/client/equity 等域，对外暴露 `/agent-api/`。
- `dayan-client`：客户端（C 端 H5/小程序后端服务），聚合 client/equity/service/order 等域，对外暴露 `/client-api/`。
- `dayan-job`：独立部署的定时任务执行器，不对外提供 HTTP 接口，仅注册到调度中心。
- `dayan-gateway`：统一入口网关，负责六端路由转发、限流、Token 校验。

### 1.2 命名规范

#### 包名

```
com.dayan.{module}              # 业务模块包
com.dayan.park.controller.admin  # 养老机构域 Admin 端控制器
com.dayan.park.service.impl      # 服务实现层
```

#### 类名（大驼峰 PascalCase）

| 类型 | 命名规则 | 示例 |
|------|---------|------|
| Controller | `{Entity}Controller` | `ParkInfoController` |
| Service接口 | `{Entity}Service` | `ParkInfoService` |
| Service实现 | `{Entity}ServiceImpl` | `ParkInfoServiceImpl` |
| Mapper | `{Entity}Mapper` | `ParkInfoMapper` |
| Entity | `{Entity}` | `ParkInfo` |
| DTO-创建 | `{Domain}CreateDTO`（用领域简称，非完整实体名） | `ParkCreateDTO` |
| DTO-更新 | `{Domain}UpdateDTO`（用领域简称，非完整实体名） | `ParkUpdateDTO` |
| DTO-查询 | `{Domain}QueryDTO`（用领域简称，非完整实体名） | `ParkQueryDTO` |
| VO-列表 | `{Domain}VO`（用领域简称，非完整实体名） | `ParkVO` |
| VO-详情 | `{Domain}DetailVO`（用领域简称，非完整实体名） | `ParkDetailVO` |
| VO-精简 | `{Domain}SimpleVO`（用领域简称，非完整实体名） | `ParkSimpleVO` |
| BO-业务对象 | `{Domain}BO`（可选，用领域简称；本项目默认用 Entity 或 VO 替代） | `ParkBO`（用于服务层内部业务聚合） |
| Converter | `{Entity}Converter` | `ParkInfoConverter` |
| Enum | `{Domain}{Field}Enum`（用领域简称，非完整实体名） | `ParkStatusEnum` |
| 常量 | `{Domain}Constants`（用领域简称，非完整实体名） | `ParkConstants` |
| 异常-业务域专属 | `{Domain}BusinessException` | `ParkBusinessException`、`EquityBusinessException` |
| 异常-框架通用 | 通用名（不加域前缀） | `BusinessException`、`ParamException`、`UnauthorizedException`、`TokenExpiredException` |
| 配置实体（DO） | `{Entity}`（映射 system_config 等配置表） | `SystemConfig`（对应 `system_config` 表） |
| Spring 配置类 | `{Module}Config`（`@Configuration` 注解） | `MybatisConfig`、`RedisConfig` |

> **实体名 vs 领域简称（双命名约定）**：本规范同时使用两套前缀，务必区分清楚，避免与实体类同名、并让传输对象更简洁：
> - **Entity / Mapper / Service / ServiceImpl / Controller / Converter** 使用**完整实体名** `{Entity}`（如 `ParkInfo`）；
> - **DTO / VO / Enum / Constants / BO** 使用**领域简称** `{Domain}`（如 `Park`）。
> - 即实体为 `ParkInfo`（对应 `park_info` 表），但其传输对象为 `ParkVO`、`ParkQueryDTO`，枚举为 `ParkStatusEnum`，常量为 `ParkConstants`，而非 `ParkInfoVO` / `ParkInfoQueryDTO`。

> **异常命名区分**：
> - **框架/全局通用异常**用通用名（不加域前缀）：`BusinessException`、`ParamException`、`UnauthorizedException`、`TokenExpiredException`、`ForbiddenException`、`NotFoundException` 等，定义在公共模块供全局复用。
> - **业务域专属异常**用 `{Domain}BusinessException`（如 `ParkBusinessException`、`EquityBusinessException`），仅当某业务域需要承载域内特有错误码/语义时才定义。

> **「config」一词的语义澄清**：代码中 `config` 在不同语境下指代不同对象，务必区分，避免命名冲突与误解：
> - **系统配置实体（DO）**：`SystemConfig`，映射数据库 `system_config` 表（KV 运行时配置，如开关、阈值），由运维/管理后台动态维护；历史项目中 `settings` 与 `config` 已合并统一为 `system_config` 一张表。
> - **Spring 配置类**：`XxxConfig`（如 `MybatisConfig`、`WebMvcConfig`），带 `@Configuration` 注解，用于声明 Bean，是静态代码。
> - **配置文件**：`application.yml` / `application-{env}.yml`，随环境（dev/sit/uat/prod）切换。
> - 禁止用 `Config` 同时命名实体和配置类；实体用 `SystemConfig`，Spring 类用 `XxxConfig` 后缀，二者不冲突。

### 1.3 分层职责

#### Controller 层

```java
@RestController
@RequestMapping("/admin-api/v1/park-infos")
@RequiredArgsConstructor
@Tag(name = "养老机构管理")
public class ParkInfoAdminController {

    private final ParkInfoService parkInfoService;

    @Operation(summary = "机构分页列表")
    @SaCheckPermission("park:info:list")
    @GetMapping
    public R<PageResult<ParkVO>> page(@Valid ParkQueryDTO query) {
        return R.ok(parkInfoService.pageByCondition(query));
    }

    @Operation(summary = "机构详情")
    @SaCheckPermission("park:info:query")
    @GetMapping("/{parkCode}")
    public R<ParkDetailVO> getDetail(@PathVariable String parkCode) {
        return R.ok(parkInfoService.getDetailByCode(parkCode));
    }

    @Operation(summary = "新增机构")
    @SaCheckPermission("park:info:create")
    @PostMapping
    public R<String> create(@RequestBody @Valid ParkCreateDTO dto) {
        return R.ok(parkInfoService.create(dto));
    }

    @Operation(summary = "修改机构")
    @SaCheckPermission("park:info:update")
    @PutMapping("/{parkCode}")
    public R<Void> update(@PathVariable String parkCode,
                          @RequestBody @Valid ParkUpdateDTO dto) {
        parkInfoService.updateByCode(parkCode, dto);
        return R.ok();
    }

    @Operation(summary = "删除机构")
    @SaCheckPermission("park:info:delete")
    @DeleteMapping("/{parkCode}")
    public R<Void> delete(@PathVariable String parkCode) {
        parkInfoService.deleteByCode(parkCode);
        return R.ok();
    }
}
```

**Controller 层规范**：
- 只做参数校验（`@Valid`）+ 权限注解（`@SaCheckPermission`）+ 调用 Service
- 禁止在 Controller 层编写业务逻辑
- 入参使用 DTO，出参使用 VO，禁止暴露 Entity
- 统一使用 `R<T>` 包装响应

#### Service 层

```java
@Service
@RequiredArgsConstructor
@Transactional(rollbackFor = Exception.class)
public class ParkInfoServiceImpl implements ParkInfoService {

    private final ParkInfoMapper parkInfoMapper;
    private final CodeGenerator codeGenerator;
    private final StateMachineEngine stateMachineEngine;

    @Override
    public String create(ParkCreateDTO dto) {
        // 1. 业务校验
        parkInfoMapper.checkNameUnique(dto.getFullName(), null);

        // 2. 生成编码
        String parkCode = codeGenerator.generate("PK");

        // 3. DTO → Entity 转换
        ParkInfo entity = ParkInfoConverter.INSTANCE.toEntity(dto);
        entity.setParkCode(parkCode);
        entity.setPublished(0);

        // 4. 入库
        parkInfoMapper.insert(entity);
        return parkCode;
    }

    @Override
    public void publish(String parkCode) {
        ParkInfo park = parkInfoMapper.selectByCode(parkCode);
        // 状态机校验
        stateMachineEngine.transition("PARK_SM", park.getStatus(), "publish");
        parkInfoMapper.updateStatus(parkCode, 1);
    }
}
```

**Service 层规范**：
- 业务逻辑全部在 Service 层实现
- 事务注解加在类级别或方法级别
- 状态变更必须通过 StateMachineEngine，禁止直接 UPDATE status
- 跨域调用通过接口依赖，禁止直接注入其他域的 Mapper
- 复杂查询在 Mapper XML 中实现，简单查询用 LambdaQueryWrapper

#### Mapper 层

```java
@Mapper

    /**
     * 分页条件查询（复杂SQL用XML）

    Page<ParkVO> selectPageList(Page<ParkVO> page, @Param("query") ParkQueryDTO query);

    /**
     * 名称唯一性校验
     */
    void checkNameUnique(@Param("fullName") String fullName,
                         @Param("excludeCode") String excludeCode);
}
```

### 1.4 异常处理规范

#### 错误码定义

错误码采用 5 位数字分段，按业务域/异常类型划分，便于前端按段统一处理：

| 错误码 | 异常类 | 含义 |
|--------|--------|------|
| 10000 | `ParamException` | 参数校验异常 |
| 10100 | `TokenExpiredException` | Token 已过期 |
| 10101 | `UnauthorizedException` | Token 无效 / 未登录 |
| 10200 | `ForbiddenException` | 权限不足 |
| 10201 | `AccountLockedException` | 账号已锁定 |
| 10300 | `NotFoundException` | 资源不存在 |
| 10400 | `BusinessException`（通用） | 通用业务异常 |
| 10500 | - | 系统内部异常（兜底） |

#### 异常定义

```java
/** 业务异常基类 */
@Getter
public class BusinessException extends RuntimeException {
    private final int code;

    public BusinessException(int code, String message) {
        super(message);
        this.code = code;
    }

    public BusinessException(ErrorCode errorCode) {
        super(errorCode.getMessage());
        this.code = errorCode.getCode();
    }
}

/** 参数校验异常 */
public class ParamException extends BusinessException {
    public ParamException(String message) {
        super(10000, message);
    }
}

/** Token 过期异常 */
public class TokenExpiredException extends BusinessException {
    public TokenExpiredException(String message) {
        super(10100, message);
    }
}

/** Token 无效 / 未登录异常 */
public class UnauthorizedException extends BusinessException {
    public UnauthorizedException(String message) {
        super(10101, message);
    }
}

/** 权限不足异常 */
public class ForbiddenException extends BusinessException {
    public ForbiddenException(String message) {
        super(10200, message);
    }
}

/** 账号已锁定异常 */
public class AccountLockedException extends BusinessException {
    public AccountLockedException(String message) {
        super(10201, message);
    }
}

/** 资源不存在异常 */
public class NotFoundException extends BusinessException {
    public NotFoundException(String entityName, String code) {
        super(10300, entityName + "不存在：" + code);
    }
}
```

#### 全局异常处理器

```java
@RestControllerAdvice
@Slf4j
public class GlobalExceptionHandler {

    /** 业务异常 */
    @ExceptionHandler(BusinessException.class)
    public R<Void> handleBusinessException(BusinessException e) {
        log.warn("业务异常: code={}, message={}", e.getCode(), e.getMessage());
        return R.fail(e.getCode(), e.getMessage());
    }

    /** Token 过期（10100） */
    @ExceptionHandler(TokenExpiredException.class)
    public R<Void> handleTokenExpired(TokenExpiredException e) {
        log.warn("Token 过期: {}", e.getMessage());
        return R.fail(10100, e.getMessage());
    }

    /** Token 无效 / 未登录（10101） */
    @ExceptionHandler(UnauthorizedException.class)
    public R<Void> handleUnauthorized(UnauthorizedException e) {
        log.warn("未授权访问: {}", e.getMessage());
        return R.fail(10101, e.getMessage());
    }

    /** 账号已锁定（10201） */
    @ExceptionHandler(AccountLockedException.class)
    public R<Void> handleAccountLocked(AccountLockedException e) {
        log.warn("账号锁定: {}", e.getMessage());
        return R.fail(10201, e.getMessage());
    }

    /** 参数校验异常 */
    @ExceptionHandler(MethodArgumentNotValidException.class)
    public R<Void> handleValidation(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
                .map(f -> f.getField() + ": " + f.getDefaultMessage())
                .collect(Collectors.joining("; "));
        return R.fail(10000, message);
    }

    /** Sa-Token 未登录 / Token 无效 */
    @ExceptionHandler(NotLoginException.class)
    public R<Void> handleNotLogin(NotLoginException e) {
        return R.fail(10101, "未登录或登录已失效，请重新登录");
    }

    /** Sa-Token 权限不足 */
    @ExceptionHandler(NotPermissionException.class)
    public R<Void> handleNotPermission(NotPermissionException e) {
        return R.fail(10200, "权限不足：" + e.getPermission());
    }

    /** 未知异常 */
    @ExceptionHandler(Exception.class)
    public R<Void> handleException(Exception e) {
        log.error("系统异常", e);
        return R.fail(10500, "系统内部错误，请联系管理员");
```

```typescript
  (response) => {
    const res = response.data
    if (res.code !== 0) {
      ElMessage.error(res.message || '请求失败')
      // 10100 Token 过期 / 10101 Token 无效或未登录：清理登录态并跳转登录页
      if (res.code === 10100 || res.code === 10101) {

          // 避免在登录页重复跳转造成死循环

            window.location.href = `/login?redirect=${encodeURIComponent(currentPath)}`
          }
        })
      }
      return Promise.reject(new Error(res.message))
    }
    return res
  },
  (error) => {
    ElMessage.error(error.message || '网络异常')
```

#### Long→String 全局序列化（雪花ID精度保护）

> 分片表使用雪花ID（64位long），超过JS安全整数范围（2^53），直接返回前端会精度丢失（如 `1868543210123456789` → `1868543210123456700`）。必须全局配置 Jackson 将 Long 序列化为 String。

```java
@Configuration
public class JacksonConfig {

    /**
     * 全局 Long → String 序列化。
     * 分片表主键为雪花ID（64位），超过 JS Number.MAX_SAFE_INTEGER (2^53)，
     * 前端 JSON.parse 会精度丢失。统一序列化为 String，前端用 String 接收。
     * 业务编码（*_code）本身就是 String，不受影响。
     */
    @Bean
    public Jackson2ObjectMapperBuilderCustomizer longToStringCustomizer() {
        return builder -> {
            builder.serializerByType(Long.class, ToStringSerializer.instance);
            builder.serializerByType(Long.TYPE, ToStringSerializer.instance); // long 基本类型
        };
    }
}
```

> ⚠️ **注意**：此配置全局生效，所有 Long/long 字段（含分页 total、count 统计值等）都会序列化为 String。前端需统一用 String 接收或 `Number()` 转换。若某些统计值确认不会超 2^53 且前端依赖数字运算，可用 `@JsonSerialize(using = NumberSerializer.class)` 局部覆盖。

#### 逻辑删除配置

```yaml
# application.yml
mybatis-plus:
  global-config:
    db-config:
      logic-delete-field: deleted        # 逻辑删除字段：deleted tinyint(1)
      logic-delete-value: 1              # 已删除
      logic-not-delete-value: 0          # 未删除
```

> **为什么不用 `NOW()` / `NULL`**：
> - `NOW()` 作为删除标记会使每条软删记录的标记值各不相同（精确到秒），无法用等值条件 `deleted = ?` 命中索引，退化为范围/全表扫描，严重影响软删数据的查询性能。
> - 「未删除 = NULL」与「已删除 = 时间戳」混用，查询计划与索引行为差异巨大，且 `deleted_at IS NULL` 的过滤代价高于 `deleted = 0`。
> - 改为 `0/1` 后，`deleted` 字段为离散值，等值查询命中索引，符合 MyBatis-Plus 主流用法，框架自动在所有查询追加 `AND deleted = 0`。

> **`deleted` 与 `deleted_at` 是两套机制，配合使用**：
> - **`deleted` tinyint(1)（0/1）**：逻辑删除标记字段，由 MyBatis-Plus 框架自动维护，所有业务查询自动过滤 `deleted = 0`。**该字段统一加索引**。
> - **`deleted_at` datetime NULL**：删除时间戳，仅作审计/追溯用途（记录何时被何人删除），不参与查询过滤，MyBatis-Plus 不自动读取。
> - 删除时同时写入：`deleted = 1`（框架自动）+ `deleted_at = NOW()`（手动或自动填充）。

#### AES 加密字段清单

| 字段 | 表 | 加密方式 |
|------|---|---------|
| `id_card` | organ_employee, client_info, supplier_info, agent_info, equity_use_person | AES-256-GCM |
| `password` | 所有 account 表 | BCrypt（不可逆） |

| `app_secret` | channel_open_platform, supplier_open_platform | AES-256-GCM |
| `bank_account` | supplier_info, distributor_info | AES-256-GCM |
| `card_secret` | equity_depot | AES-256-GCM |

> **加密算法选择：AES-256-GCM（禁止使用 ECB）**
> 身份证号、银行卡号等敏感字段存在大量重复前缀或固定模式（如身份证前 6 位地区码、银行卡 BIN）。**ECB 模式对相同明文产生相同密文**，攻击者可通过密文比对、字典攻击还原明文，且 ECB 无完整性校验，密文可被篡改而不被发现。
> 因此统一采用 **AES-256-GCM**（Galois/Counter Mode）：
> - **带认证的加密（AEAD）**：同时保证机密性与完整性，解密时自动校验 GCM Tag，密文被篡改会抛出异常；
> - **随机 IV**：每次加密生成 12 字节随机 IV，相同明文每次密文不同，抗字典攻击；
> - **密文存储格式**：`Base64( IV(12B) + ciphertext + Tag(16B) )`，IV 与密文同库存储，无需额外保存；
> - **禁止复用 IV**：同一密钥下 IV 严禁重复，否则破坏 GCM 安全性。

```java
// 加密组件（AES-256-GCM）
@Component
public class AesEncryptor {

    private static final String TRANSFORMATION = "AES/GCM/NoPadding";
    private static final String ALGORITHM = "AES";
    private static final int GCM_TAG_LENGTH_BIT = 128;   // 16 字节 Tag
    private static final int GCM_IV_LENGTH_BYTE = 12;    // 12 字节 IV

    @Value("${security.aes.key}")
    private String aesKey;   // Base64 编码的 32 字节(256 位)密钥

    private SecretKey toKey() {
        byte[] keyBytes = Base64.getDecoder().decode(aesKey);
        return new SecretKeySpec(keyBytes, ALGORITHM);
    }

    /**
     * AES-256-GCM 加密
     * @return Base64( IV(12B) + ciphertext + Tag(16B) )
     */
    public String encrypt(String plainText) {
        if (plainText == null) {
            return null;
        }
        try {
            // 1. 生成 12 字节随机 IV（每次不同，禁止复用）
            byte[] iv = new byte[GCM_IV_LENGTH_BYTE];
            SecureRandom.getInstanceStrong().nextBytes(iv);

            // 2. 初始化 Cipher（通过 AlgorithmParameters 保存 IV）
            Cipher cipher = Cipher.getInstance(TRANSFORMATION);
            GCMParameterSpec spec = new GCMParameterSpec(GCM_TAG_LENGTH_BIT, iv);
            cipher.init(Cipher.ENCRYPT_MODE, toKey(), spec);

            // 3. 加密，输出末尾自带 16 字节 Tag
            byte[] cipherTextWithTag = cipher.doFinal(plainText.getBytes(StandardCharsets.UTF_8));

            // 4. 拼接 IV + ciphertext + Tag，整体 Base64
            ByteBuffer buffer = ByteBuffer.allocate(iv.length + cipherTextWithTag.length);
            buffer.put(iv);
            buffer.put(cipherTextWithTag);
            return Base64.getEncoder().encodeToString(buffer.array());
        } catch (GeneralSecurityException e) {
            throw new BusinessException(10500, "加密失败");
        }
    }

    /**
     * AES-256-GCM 解密
     * @param ciphered Base64( IV(12B) + ciphertext + Tag(16B) )
     */
    public String decrypt(String ciphered) {
        if (ciphered == null) {
            return null;
        }
        try {
            byte[] decoded = Base64.getDecoder().decode(ciphered);
            // 1. 截取前 12 字节 IV
            byte[] iv = Arrays.copyOfRange(decoded, 0, GCM_IV_LENGTH_BYTE);
            byte[] cipherTextWithTag = Arrays.copyOfRange(decoded, GCM_IV_LENGTH_BYTE, decoded.length);

            // 2. 解密并校验 Tag（Tag 校验失败会抛 AEADBadTagException）
            Cipher cipher = Cipher.getInstance(TRANSFORMATION);
            GCMParameterSpec spec = new GCMParameterSpec(GCM_TAG_LENGTH_BIT, iv);
            cipher.init(Cipher.DECRYPT_MODE, toKey(), spec);
            byte[] plainBytes = cipher.doFinal(cipherTextWithTag);
            return new String(plainBytes, StandardCharsets.UTF_8);
        } catch (GeneralSecurityException e) {
            throw new BusinessException(10500, "解密失败或密文被篡改");
        }
    }
}
```
